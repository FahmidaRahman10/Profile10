# Academic Faculty Website — Dr. Fahmida Rahman

A responsive static academic portfolio designed for free GitHub Pages hosting.

## Preview locally
Open `index.html` in your browser. An internet connection is needed to load the Google Fonts; the site still works without them.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your actual GitHub username).
2. Upload `index.html` and the `assets` folder to the repository root on the `main` branch.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Your site should become available at `https://YOURUSERNAME.github.io/` after deployment.

## Customize before publishing
- Edit your name, title, biography, research, and teaching details in `index.html`.
- Replace the publication placeholder with verified full citations and links.
- Replace `YOUR_EMAIL@example.com` in the publication placeholder, or remove the placeholder link entirely.
- Add a professional headshot and relevant project images if desired.
- Add your verified email, Google Scholar, ORCID, LinkedIn, and Rowan faculty profile URLs.
- Update colors and typography in `assets/style.css`.

The transportation network illustration is original SVG markup. This template uses no JavaScript frameworks or build steps.
